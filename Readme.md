# AI Vision Guide with Real-time obstacle detection

## Key Features
- Real-time object detection and depth estimation
- Text-to-speech navigation instructions
- Google Maps integration for navigation
- Hazard detection and alerts

## Tech Stack
- React
- FastAPI
- Google Gemini API
- YOLOv8
- MiDaS

## Installation & Setup

### Backend
```bash
cd backend
pip install -r requirements.txt
```

### Frontend
```bash
cd frontend
cp .env_example .env (insert your API keys here)
npm install
```

## Usage

### Backend
```bash
cd backend
python main.py
```

### Frontend
```bash
cd frontend
npm run dev
```
